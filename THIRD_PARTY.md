# Third-party credits

## Skiper UI

Free source inspected from the official registry on 2026-10-18:

- [Skiper40 / CssLink](https://skiper-ui.com/r/skiper40.json): `Link000` transform-origin underline interaction adapted to `.skiper-link` in `style.css`, with native HTML, focus-visible support, and reduced motion. Author: @gurvinder-singh02 / gxuri. Original source notes inspiration from cursor.com.
- [Skiper31 / Text Scroll animation](https://skiper-ui.com/r/skiper31.json): `CharacterV1` distance-from-center x/rotateX concept adapted to a GSAP/native-DOM implementation for the rooftop quotation in `script.js`. It does not import the original React component, Lenis, or Framer Motion. Travel distances have been reduced for readability and phone layouts.

The official registry source permits free personal/commercial use and modification with attribution. A visible [Skiper UI](https://skiper-ui.com) attribution is included in the site footer. [Quick start and usage terms](https://skiper-ui.com/docs/quick-start).

[The public catalog](https://animmasterlib.dev/) was reviewed. Its component source is sold as packs, and no licensed files were supplied. No Animmaster source was copied or installed. The hero parallax, flower drawing, typewriter, and reader behavior are independently implemented.
